# بندرِ ترم (Term Harbor)

یک وب‌اپ فوری، آفلاین و تک‌منظوره که گزارش‌های خروجی دانشگاه (**گزارش ۲۱۲** PDF،
**گزارش ۱۰۲** و **گزارش ۱۱۰** Excel) را به یک برنامهٔ هفتگی تمیز تبدیل می‌کند —
با تشخیص تداخل، برگهٔ قابل چاپ، و خروجی PNG با یک کلیک.

> English? [See the English README](README.md)

[اجرای آنلاین برنامه](https://0antuosh0-create.github.io/course-scheduler/)

## چرا

پورتال‌های انتخاب واحد سه گزارش جداگانه می‌دهند و برنامه‌ریزی هفتگی را به عهدهٔ خودتان
می‌گذارند. بندرِ ترم این گزارش‌ها را یکی می‌کند، هفتهٔ شما را به‌شکل جدول زمانی واقعی
نشان می‌دهد، تداخل‌ها را علامت می‌زند (کد تکراری، هم‌پوشانی کلاس‌ها، تداخل امتحان‌ها)،
و یک برگهٔ تمیز می‌سازد که می‌توانید چاپ کنید، PDF ذخیره کنید، یا به‌صورت تصویر به
اشتراک بگذارید.

## امکانات

- **بارگذاری با کشیدن و رها کردن** سه گزارش (PDF + دو فایل Excel)
- **موتور ادغام** — ترکیب اطلاعات دروس بین گزارش‌ها با تحمل فیلدهای ناقص
- **تقویم هفتگی** — شبکهٔ شنبه تا پنج‌شنبه، ۷:۰۰ تا ۲۰:۰۰، بلوک‌های تداخل کنار هم
- **تشخیص تداخل** — کد تکراری، هم‌پوشانی کلاس‌ها (بحرانی)، تداخل ساعت امتحان، هشدار امتحان هم‌روز
- **خروجی** — برگهٔ خودکفای قابل چاپ (A4 افقی؛ برنامه‌های طولانی ممکن است چندصفحه‌ای شوند) و تصویر PNG با کیفیت ۲ برابر
- **پشتیبان‌گیری و بازیابی (JSON)** — خروجی کامل داده‌ها و دروس انتخابی در فایل JSON و بازیابی سریع در هر زمان یا دستگاه دیگر
- **کاملاً آفلاین** — مستقیم `index.html` را باز کنید؛ بدون سرور، بدون تلمتری
- **بدون نصب هیچ چیز** — pdf.js، SheetJS و قلم وزیرمتن داخل `vendor/` باندل شده‌اند

## اجرا

مرحلهٔ بیلد ندارد. یا:

۱. روی `index.html` دوبار کلیک کنید، یا
۲. پوشه را سرو کنید: `python -m http.server 8080` → باز کردن `http://localhost:8080`

برای فعال شدن برنامه‌ریز، گزارش ۲۱۲ (دروس مجاز) و گزارش ۱۰۲ (فهرست دروس) را بارگذاری کنید.
گزارش ۱۱۰ اختیاری است و اطلاعات مکان، آزمون و توضیحات را تکمیل می‌کند.
دروس را انتخاب کنید، تداخل‌ها را بررسی کنید و از پنجرهٔ خروجی، PDF یا PNG بگیرید.

## حریم خصوصی

گزارش‌ها داخل مرورگر پردازش می‌شوند و بارگذاری اینترنتی ندارند. نسخهٔ آنلاین، فایل‌های
ثابت برنامه را از GitHub Pages دریافت می‌کند؛ پوشهٔ دانلودشده آفلاین کار می‌کند.
اطلاعات استخراج‌شده و انتخاب‌ها در حافظهٔ محلی مرورگر ذخیره می‌شوند. به‌ویژه روی
رایانهٔ مشترک، با دکمهٔ بازنشانی برنامهٔ ذخیره‌شده را پاک کنید. گزارش‌های شخصی در مخزن نیستند.

## پارس PDF چطور کار می‌کند

گزارش ۲۱۲ متن فارسی را به **ترتیب بصری** ذخیره می‌کند (رشته‌های گلیف راست‌به‌چپ با
ارقام چپ‌به‌راست) که استخراج ساده‌اش متن به‌هم‌ریخته می‌دهد. بندرِ ترم ترتیب منطقی
واژه‌ها را بازسازی می‌کند: رشته‌های گلیف با مختصات x مرتب می‌شوند، با اندازه‌گیری فاصله‌ها
به کلمه مونتاژ می‌شوند، هر رشته وارونه و دوباره در توالی راست‌به‌چپ چیده می‌شود —
و رشته‌های عددی دست‌نخورده می‌مانند تا کد درس‌ها سالم بماند.

## ساختار پروژه

```
course-scheduler/
├── index.html      # رابط تک‌صفحه‌ای
├── styles.css      # سیستم طراحی (پالت کاغذ/جوهر، راست‌چین-محور)
├── app.js          # پارسرها، موتور ادغام، تقویم، تداخل‌ها، خروجی‌ها
└── vendor/
    ├── pdf.min.js / pdf.worker.min.js   # pdf.js (Apache-2.0)
    ├── xlsx.full.min.js                 # SheetJS CE (Apache-2.0)
    └── Vazirmatn-wght.woff2             # قلم وزیرمتن (OFL-1.1)
```

## مجوز

pdf.js و SheetJS CE اعلان‌های مجوز Apache-2.0 خود را حفظ می‌کنند؛ قلم وزیرمتن
تحت OFL-1.1 است. برای کد خود برنامه هنوز مجوز جداگانه‌ای ارائه نشده است.
